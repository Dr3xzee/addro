Dev Questions

What tech stack do you use?

Frontend: React, Next.js, Vue, or Angular. Backend: Node.js, Python (Django/FastAPI), or Go. Mobile: React Native or Flutter. Cloud: AWS, GCP, or Azure. We pick the stack based on your project needs — not our comfort zone.

Do I own the source code?

100%. Once final payment is made, the entire codebase, documentation, and deployment configs are yours. We don't lock you in. We don't use proprietary frameworks. Standard, well-documented code that any competent developer can pick up.

How do you handle changes mid-project?

Small tweaks within scope? No problem. Major feature additions or pivots get quoted separately before implementation. We communicate immediately if a request affects timeline or budget — no surprise invoices at the end.

What happens after launch?

Every project includes 30 days of post-launch support for bug fixes and minor adjustments. After that, we offer monthly maintenance retainers (starting at $500/mo) for updates, monitoring, and feature additions. We stay — that's the Addro difference.

Can you work with our existing codebase?

Yes, but we do a code audit first (billed separately at $300). If the codebase is salvageable, we'll build on it. If it's spaghetti, we'll be honest and recommend a rebuild. No point pouring new wine into cracked bottles.
